## Version 10 - Mejoras desde V9

### Nuevas Características
- Soporte para pantalla completa en monitor secundario
- División dinámica de pantalla (1/4, 1/2, pantalla completa)
- Sistema de prioridad para recursos multimedia (1,2,3)

### Mejoras
- Ventanas sin bordes y transparentes
- Mejor organización del contenido y recursos
- Banners independientes en cada sección
- Carga dinámica de GIFs, videos e imágenes
- Sistema de scroll mejorado para contenido.txt

### Cambios Técnicos
- Nueva estructura de ventanas sin solapamiento
- Control de foco y eventos mejorado
- Actualización en tiempo real del contenido
- Mejor gestión de recursos multimedia
- Sistema de capas z-index optimizado

### Uso
1. Seleccionar tamaño de división (1/4, 1/2, completo)
2. Elegir posición para contenido.txt
3. Los recursos multimedia se distribuyen automáticamente según prioridad:
   - Archivos con prefijo 1: primera ventana disponible
   - Archivos con prefijo 2: segunda ventana disponible
   - Archivos con prefijo 3: tercera ventana disponible
